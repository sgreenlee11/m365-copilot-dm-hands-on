# Microsoft 365 Copilot District Manager Hands-On Site

Static GitHub Pages site for a Microsoft 365 Copilot hands-on lab for District Managers and multi-store field leaders. Adapted from [m365-copilot-vip-hands-on](https://github.com/sgreenlee11/m365-copilot-vip-hands-on) (executive session); that site is unchanged.

Live site: https://sgreenlee11.github.io/m365-copilot-dm-hands-on/

## Activity flow (50 minutes)

1. Welcome and objectives
2. Prompting pattern (goal + context + source + expectations)
3. Catch up: district pulse across email, chats, meetings, and Teams channels
4. Prepare: store visit brief and walk checklist
5. Analyze: district scorecard (Copilot in Excel) or customer feedback by store (Analyst)
6. Cascade: district action plan in Word, store manager Teams post, optional PowerPoint call deck
7. Follow through: store commitment tracker and Outlook recap from the district call
8. Lead responsibly

## Included assets

- `assets/Demo_District_Store_Performance.xlsx` - fictional 10-store district (District 07): Store Scorecard, Department Performance, People and Readiness, Store Visit Log, Notes and Assumptions.
- `assets/Demo_District_Customer_Feedback.csv` - fictional store-level customer feedback for the same district.
- `assets/Demo_District_Call_Transcript.docx` - fictional weekly store manager call transcript (fallback for Activity 7).
- `assets/district_manager_prompt_library.csv` - generic District Manager prompt library.

All demo data is fictitious and intended for training use only. The data is seeded with deliberate stories (a declining store, a strong-sales store with a safety risk, a shrink-versus-customer-access trade-off, a seasonal set lag, an improving store, a best-practice store) and two data-quality issues for participants to catch.
